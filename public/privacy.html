Tehon プライバシーポリシー

2026年11月1日

対象は、Tehon のウェブアプリ（tehon.pikoponpoko.workers.dev）、デスクトップ版、ブラウザ拡張機能です。

扱うデータ

  • Dropbox のアクセストークン：利用者の端末内にだけ保存します（ウェブアプリは IndexedDB、拡張機能は chrome.storage）。
  • 保存する画像・動画・URL、フォルダ名、タグ：利用者の Dropbox の「アプリ/Tehon」フォルダに直接保存します。
  • 拡張機能は、利用者が拡張機能を開いたときだけ、表示中のページの画像・動画の URL を読み取ります。保存するのは利用者が選んだものだけです。

送信先

  • データは利用者の端末から Dropbox の API（api.dropboxapi.com、content.dropboxapi.com）へ直接送ります。開発者のサーバーには送りません。
  • ウェブアプリでブックマークのサムネイルを表示するとき、そのページの URL を Tehon のサーバー（Cloudflare Workers）に送り、プレビュー画像を取得します。URL は記録しません。
  • アクセス解析、広告、第三者へのデータ提供は行いません。

削除

拡張機能の「接続を解除」、またはアプリの設定から Dropbox の接続を解除すると、端末内のトークンを削除します。Dropbox に保存したファイルは、利用者の Dropbox から削除できます。

Privacy Policy (English)

This covers the Tehon web app (tehon.pikoponpoko.workers.dev), the desktop app and the browser extension.

  • The Dropbox access token is stored only on the user's device (IndexedDB in the web app, chrome.storage in the extension).
  • Images, videos, URLs, folder names and tags are saved directly to the user's own Dropbox, in the Apps/Tehon folder.
  • The extension reads the image and video URLs of the current page only when the user opens it, and saves only the items the user selects.
  • Data goes from the user's device straight to the Dropbox API. It is not sent to the developer's servers.
  • To show bookmark thumbnails, the web app sends the bookmarked page's URL to Tehon's server (Cloudflare Workers), which fetches its preview image. URLs are not logged.
  • No analytics, no advertising, and no data is shared with third parties.
  • Disconnecting Dropbox in the extension or the app deletes the token from the device. Saved files can be deleted from the user's Dropbox.
